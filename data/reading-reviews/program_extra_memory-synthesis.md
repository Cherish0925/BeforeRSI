## 从工具持久化到经验抽象

ATLASS 与 OpenAgent 都固定外层 LLM 工作流，通过代码、环境和经验改变后续任务行为。ATLASS 的工具元数据和 Python 程序可以继承，但论文的八个示例是功能展示，不能读成严格的八题成功率。其空库与已有工具的单例成本约为 $0.1008 与 $0.0624，外部 API、人工执行批准等费用并未一并计入。保留 insufficient 是证据判断，不是因为工具机制无关或全文拿不到。

OpenAgent 的更强证据来自 21 个仓库、113 个基础任务及三个仓库提示条件，但三个条件形成的 339 查询不能当成 339 个独立任务。主表 GPT-4 的 47.3 对 ReAct 24.6 是首次执行且不启用跨任务摘要的结果。经验表则先运行 Qlib/AizynthFinder 的 51 个查询，再在同一 51 查询上复用部署环境和摘要，GPT-4 从 47.0 到 82.3；它证明复用价值，却没有分离环境缓存与经验规则，也没有检验新任务。论文 v3 的完整判断还需记录裁判正文与附录评分量表不一致。

ReCreate 把“记住经验”推进到“决定修改哪个组件并抽象为领域规则”。同一批实例使用共同 scaffold，局部优化器分别提交 diff 和理由，综合器去掉实例特例并解决冲突。它区别于单纯扩充工具库，也区别于执行时临时调工具。十三设置宏均值 66.15 对 ExpeL 60.62 混合了二值通过率与 DA-code 连续分数；去领域综合后 SWE/DA/DS 的 60.19/39.77/77.74 降至 57.09/37.83/75.96。SWE Full 排除 Verified 后选开发集，再测 Verified 的附加实验提供实际领域留出证据。

与已选核心比较，Meta-Harness 对反馈接口有更受控的原始轨迹/摘要/仅分数消融，并明确冻结产物做新任务和跨模型迁移；Meta-Team 则保留实际参与者的局部上下文，通过队友交互做归因，并修改个体、关系和团队三层状态。ReCreate 的集中批综合是值得保留的互补路线，尚不需要作为第三个相同反馈诊断主代表。其更新算法与优化器代码保持固定。

ReCreate v3 有两处必须保留的报告边界：App I 声称 13 个数据集、N=1681 的 McNemar 检验，而 App F 的测试数合计 1899；1681 正好等于去除三个 DA-code 连续分数集合后的十个二值集合，故实际检验范围不清。App M 图21生成记忆要求运行 expected_tests.txt 中的 FAIL_TO_PASS 测试，与图18/19生成提示禁止读取或触碰测试的规则冲突。这是公开产物的内部控制矛盾；不能据此断言测试实际可达，更不能断言原论文分数已经污染。

## 反馈变密，不等于反馈独立

CoEvoSkills 用独立验证会话检查任务产物；当局部测试失败时改技能，当局部通过而隐藏 oracle 失败时改测试。这个分工使可解释测试成为诊断层，但 oracle 仍决定选优、停止及验证器升级。它不是 ground-truth-free，也不是仅靠生成验证器完成自举。

主要 SkillsBench 结果覆盖 85 任务：Opus 技能演化达 71.1，对无技能 30.6、人类技能 53.5；去验证器为 41.1，只保留上下文为 42.4。不过去验证器同时改变反馈量与计算过程，缺少固定验证器对照和严格等预算对照。App D 明确技能主要跨当前任务迭代保存；迁移实验把各任务的已有技能包换给其他执行模型，不能称为新任务技能库泛化。公开例子又用 75%/100% 数值 oracle 反馈解释算法变化，与正文描述的仅二值 oracle 反馈存在口径张力；不应进一步推定它看到了隐藏测试内容。相较 RQGM、Meta-Harness 等核心，本作补足测试诊断层，不提供改进器源码自修改证据。

## AI4AI 的真实产物与成本边界

Self-Evolved ABC 的主要对象是外部 EDA 工程程序。固定规划/编码团队更新 FlowTune、编排和 mapper，用 CEC 检查正确性，再按工艺与电路 QoR 选择集成版本。相对已集成的 vanilla 基线，全模块归一化代价 0.917；相对未集成原始 ABC 的基线优势有一部分来自初始化，不能全部算为自主演化增益。论文约 2400 美元优化总额、每轮 2–3 小时和 87 核 CPU，仍不等同完整生产部署成本。没有留出电路/新工艺迁移证据。其 Self-Evolving Rulebase 允许调整规划规则，所以也不能简单标成提示完全不变；只是论文没有具体规则轨迹及因果消融，不能据此升格为改进器自改。

AutoTTS 则优化冻结 LLM 的推理控制程序，保留外部搜索器不变。它在 AIME24 上利用预采集分支轨迹发现 CMC，再将冻结控制器用于 AIME25、HMMT25及额外模型/GPQA。某些设置以更少生成 token 获得更好结果，例如 Qwen1.7B 的 β=0.5 在两留出集均值 38.6、343.5k tokens，对 ASC 34.3、593.6k；但 4B 和 8B 的部分设置被 ASC 同时在准确率和 token 成本上压过，不能概括为全面 Pareto 优越。所有结论基于预采集轨迹回放，64 次重采样也不是64次独立研发。

约 39.9 美元、160 分钟是控制器发现过程，不包含完整轨迹准备和在线 probing 延迟；附录代码中排序后仍会探测全部活跃分支，不能把注释中“全局 probe 预算”当作已实现的调度。消融表的 Avg 还包含搜索用 AIME24，不能照正文把该列全称为 held-out。AutoTTS 为自动研发推理控制器提供具体增量，作为 support 接在程序搜索与反馈设计路线下最合适。
