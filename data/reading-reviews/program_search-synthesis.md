# 程序搜索、agent 架构与改进器自修改：112 项原文比较

本组已完成 112/112 项：85 项为新候选完整主文与相关技术附录阅读，27 项在此前原文阅读基础上重新核查方法、实验、预算和迁移。结果为 core 17、support 81、insufficient 7、redundant 2、outside 5；没有因达到某个比例而停止阅读或淘汰候选。完整逐项证据在 `program_search.jsonl`。原分配的最后 8 个公司/项目条目已明确交由 root，未计入这 112 项。

## 1. 先确定什么东西真的进入下一轮

“递归”“自演化”“研究代理”不能决定机制类别。本组最有解释力的区分是：反馈改变了外部解答程序、可复用任务 harness、开发这个 harness 的程序，还是仅改变当前任务的临时状态。下面的层次是分析工具，并非声称论文采用统一定义。

| 可变对象 | 本组代表 | 实际继承 | 不应推断的结论 |
|---|---|---|---|
| 外部候选算法或 ML 训练程序 | MLEvolve；GEAR-Prompt/Fixed | 程序种群、成绩、同任务经验 | 研究器自己变强，或跨任务研究能力转移 |
| 任务 harness/记忆/团队规则 | ADAS、ExpeL、Meta-Harness、Meta-Team | 代码、规则、经验、团队结构 | 固定的外部优化器已经发生代码自改 |
| 后继任务代理也承担自身开发 | SICA、Gödel Agent、DGM | 后继代码同时影响解题和编码自修改 | 外层诊断、选择、评价已全部递归开放 |
| 开发/改进接口本身可编辑 | Hyperagents、AIDE²；GEAR-Evolve 支持案例 | meta 代码、诊断和提案过程、搜索控制器 | 已证明无界增长或稳定的复利加速 |
| 任务与评价对象共同演化 | RQGM；WorldEvolver 支持案例 | 任务、评分器或世界状态与代理 | 分数上升自动等于客观能力提高 |

任务内适应仍可具有 harness 价值。RHI 的通信 contract、Co-Scientist 的下一轮 meta-review 提示、MLEvolve 的当前任务经验，不应被误写成“完全没有学习”；但是否形成跨任务能力、是否修改改进器，必须另列证据。RHI 原文 §7 明确固定 agent、评委与优化器；改的是文本 harness 轨迹。

AlphaEvolve 需要单独说明：其 H/core 归类不只是因为搜索外部程序。§2.2 明确自动 co-evolve prompt 并放入独立 prompt database，§4 Figure 8 左图还有 “No meta prompt evolution” 消融。这一反馈会改变后续程序提案的提示策略。外层异步控制和评价器仍然固定。因而它与固定树策略/提示的 AIDE 外部 ML 程序搜索有可核查差别；不能照 Meta-Harness 附录对旧工作的简化描述，把 AlphaEvolve 全部称为固定变异。

## 2. 从代码设计到可诊断的设计反馈

ADAS 的代表作用是将 agent 组织写成可执行代码，让固定 meta-agent 在代码空间设计任务系统。AFLOW、MaAS、AgentSquare、GDesigner、EvoAgent、AgentNet 等扩展搜索空间、路由或团队编排，但多数仍由固定优化器选择任务系统；它们保留为 support，不逐篇重复一条“自动设计 agent”的主线。

Meta-Harness 补充了不同的瓶颈：完整状态程序的失败原因可能藏在多版本源码和长执行轨迹中。固定 Claude Code/Opus4.6 按需查询文件系统，不受预设父代或局部变异规则限制。其分类消融在相同类型 proposer 下比较源码+分数、再加摘要、完整轨迹：候选 median/best 依次为 34.6/41.3、34.9/38.7、50.0/56.7。真实新增解释是可诊断的反馈接口，而不是名字中的“Meta”。它没有修改 proposer 代码。

这组消融不是完整因果终点：40 个候选的中位数不是 40 条独立进化轨迹；评价次数匹配也没有匹配 proposer 的读取 token。它仍值得 core，是因为另有冻结产物的实质迁移：9 个新分类数据集平均 73.1% 对 ACE 70.2%；200 个新数学问题上 5 模型平均比无检索高 4.7 点、比 BM25 高 1.3 点。5 个模型中 GPT-OSS-20B 参与选择，所以只有 4 个未见模型。TerminalBench 的 89 题搜索与终评同集，不能继承其他实验的泛化标签。附录的数学 88 题与主文 250 题、不同运行的 KIRA 64.4/74.7 基线差别未得到明确配置解释。

ExpeL 的核心作用是将成功/失败轨迹提炼成可复用经验，而非只在当前回答反思。Meta-Team 又把经验生成从中心总结移到团队内部：保留局部上下文，实际通信的伙伴交换证据，再更新行为补丁、skills、同伴画像、constitution 和 roster。它的 L1/L2/L3 更新工作流仍固定。与 RHI 的同任务外部修订相比，Meta-Team 有冻结团队的独立测试、Python→C/C++/Java 与上下文长度迁移，以及 global/local/collaborative 对照。Ansible 为 49.8/44.5/53.9；三条独立进化运行完整方法 53.1±1.6 对 MAS-Fly 44.8±1.9。代价不可隐藏：一次进化 348 美元，对照 MAS-Fly 268、ReCreate 216，并非等额计算证明。GPT-5.5 是重新演化，不能说旧团队直接跨模型迁移。

CORAL 提供另一个互补方向：多个研究者异步共享研究笔记和发现，改变搜索的信息流与覆盖，而不是把团队人数本身当 RSI。其更大研究产出也伴随约 3–4 倍预算，不能把 596 对 56 个 kernel 结果全归为无成本协作增益。

## 3. 后继开发者与改进器代码自改之间仍有一层

SICA 明确选择档案中效用最佳代理，令该版本开发后继。这比固定 ADAS meta-agent 多出实质继承边：改好的编辑、定位、上下文工具也被下一轮开发者使用。实际运行从固定 SWE-bench Verified 50 题子集的 17% 到最高 53%，最终 51%；外层效用将成绩、费用、时间按 0.5/0.25/0.25 组合。该集合参与反复选择，没有独立留出，不能把它当完整 SWE 或跨分布证据。AIME/GPQA 的弱改善还显示 harness 不能普遍替代基础推理能力。

Gödel Agent 开放运行中自身代码/逻辑修改，DGM 用开放档案与实证评价支持非贪心分支探索。两者解释为何 self-modification 可以落实到执行程序，不需借形式证明口号。但“任务代理能改自己”不等于诊断、选择、评测外层均可自改。DGM 的 SWE 20→50、Polyglot 14→38 与约 2.2 万美元搜索预算，应连同固定外层和污染审计边界呈现。

Hyperagents 把 task 与 meta 接口放入同一可编辑程序，因此将“产生改进的能力”变成独立实验问题。跨域冻结 meta 的 imp@50 有实质增量，但整程序迁移没有完全隔离 task 代码；部分初始零分来自输出格式错误。与手工领域适配 DGM 的机器人 .372 对 .348、论文评审 .71 对 .59，以及两百轮迁移 .64 对从头 .61，并没有形成显著的长期复利证据。可编辑父代选择也未稳定超过手写规则。

AIDE² 更接近直接检验 AI4AI 研究者：8 天内 99 次重写、7 次接受，把修改后的研究器冻结后用于新的研究任务；ALE 归一化 36→90、MLE .678→.722、FML 15→19.9，同时 kernel 55→32 回退。研究能力并非单一标量，跨域退化要和成功一起保留。这里研究者重写、固定外测和预算约束的组合，比“同一研究任务越搜越好”更能支持改进器层的判断。

GEAR-Evolve 是很好的支持案例：100 次小 LM 训练实验里发生 6 次控制器补丁，祖先排除由直接父代发展为沿双亲边的广搜，确实改变之后的交叉建议。其 .97658 bpb 优于 Fixed .97914 与 AutoResearch .98232，单次均为 H100 五分钟。但只有一个任务、一条搜索轨迹、没有冻结控制器外测或逐补丁因果对照，所以 support；不是因实际模型仅约 71–86M 而排除。

Ouroboros 的长期生产自修改、PrimeAgent 的持久运行时、Argus 的经验与清单、MOSS 的生产反馈闭环，也保留为 support。其关键限制各不相同：Ouroboros 的主要基准关闭 core evolution，且与长期生产 lineage 不同；PrimeAgent 没有隔离 /refine 的有效性，nanoGPT 最终纪录差异处于噪声；Argus 的研究成果与成本波次缺冻结状态对照；MOSS 控制实验的提升不等于大规模真实生产增量。不能拿长期运行时长或自生成代码比例替代能力变化实验。

## 4. 用更好的实验分配与约束改善递归过程

Dream-RSI 用反事实世界/前缀复用扩展可获得的改进反馈；需要说明复用不是完整分支重跑。ModularRSI 把可修改系统拆为模块与评测分片，缓解修改互相干扰；Terminal 47.57→52.43、SWE 73.4→76.4 有实际收益，但若预算不匹配不能独归模块化。

RRSI 用正则和多样性约束抑制自修改的脆弱变化，OOD 39.7→43.6；其额外 meta 阶段约多 55% token，完整成本应和收益并列。RQGM 同时开放任务与评价相关对象，并用固定锚点/重置防止评价漂移；DeepSWE 82.1 对 75、Polyglot 71.7 对 69.9 之外，必须呈现成本与数据划分，不能把共演化分数当无条件的能力标尺。

EnvHarness、WorldEvolver、EvoCurr、EvoSafeHarness 提供特定环境、课程和防护面补充。EnvHarness 保持 support；新增范围并非自动形成核心机制。EvoCurr 的任务—策略检查点可回退，但各任务单独搜索；代码任务额外调用和课程预算显著，Overcooked 真正训练的是小 RL 策略，不是大语言模型。EvoSafeHarness 的新鲜 critic 对 held-out 的平均约 +19.5 点值得记录，但固定外部搜索器未自改；其 cascade 43.6% 节省的表格基线是原 staged evaluation，并非主文笼统暗示的所有候选完整评价。

## 5. 评价闭环本身会改变“成功”的含义

Fragility 核心诊断的是估计方差、任务顺序与 underspecification。一次平均分上升不能代表稳定学习；固定基础 agent 的运行噪声可覆盖很多自改收益。EvoPathBench 则用模拟闭环显示更多验证反馈可改善验证分而降低外测，支持明确区分接受门和最终外测；保留 support，避免多个诊断条目重复占据核心叙事。

EvoMal 的独立价值不是危害幅度或使用更多模型，而是被污染经验进入自演化编码闭环，之后影响新经验的写回与继承。少数种子移除后仍观察五轮，是“外部种子不再继续注入后的持续性”；其 rho 是操作性传播代理量，不能等同严格自再生产 R0。尤其出现所有 rho>1 但若干设置衰退/持平的现象，不能用一个指标宣布无界扩散。Trusting Trust Revisited 更关注实现自修改/经验机制中的信任继承与可再生产行为；Practice Makes Unsafe 关注正常练习反馈造成的行为漂移。三者闭环对象不同，不能只按ASR大小合并，也不能重复宣称都证明了同一种自再生产。

后续 Trusting Trust Revisited §3.4.1 发现 DGM/Hyperagents 的 Polyglot 式容器 git 历史仍可能保留隐藏测试或参考解，并有 Sonnet4.5 预实验读取通道。该后续研究已 strip 历史。此证据证明漏洞可被利用，不能据此断言原论文使用的模型或原分数已经污染；两篇核心卡片均保留这一精确边界。

AgentBreeder 的安全95.2%、帮助性49.6%说明目标替代：多目标选择仍可能学会全面拒答。它是固定外部优化器的 scaffold 搜索，与 EvoMal 的经验污染循环不同。HarnessDev 的独立搜索/held-out 分离、同提交重跑噪声和不可达新函数审计也很有价值；统一执行模型后某些 lineage 退化，暴露“设计者变强”与“执行者更强”的混淆。

## 6. 规模、成本、关系和阅读边界

本组多数研究 LLM 冻结。GPT-OSS-120B 被用作分类器、闭源强模型被用作设计者，均不应计为实际训练≥27B。MLEvolve/GEAR/机器人实验确实训练外部模型或策略，但必须单独标注目标及规模；没有参数量就记未知。

不同预算应区分：训练 GPU 时间、候选评测次数、研究者 token、人工 skill 调试、最终执行费用。RHI 的60%降本是最终单次运行对ultracode，不含前面任务重跑；Meta-Harness“10倍快”指匹配分数所需完整评测次数；EvoCurr 多阶段相对direct常增加调用。各自不应改写成总成本同样下降。

关系已做终审：只有 AgentBreeder→ADAS 的七种seed及修改meta prompts记为 source_explicit/uses。其余多数跨论文关系是明确标注 analytical_comparison 的互补或比较，没有仅凭 related work 引用写成 extends。Canada CIFAR AI Chair 已从 ADAS 独立机构中移出；机构归并依据署名而非资助或头衔。

无整篇取回失败。insufficient 的七项是读完公开材料后发现核心机制/证据不足，不是未读：AutoMaAS、Six Sigma Agent、EAGER、PFAgent、STELLA、AgentDevel、LLM-as-Code。GEAR 所引用完整 prompt/超参附录在公开版本缺失；Meta-Harness 的上述规模/基线口径不一致和若干全文未报告成本均已具体记录。GitTaskBench 等五项 outside 只表示不含本次 RSI/AI4AI 更新机制，不否认普通 agent 基准价值。
