# 记忆、技能、上下文与工具组：持续阅读中的机制谱系

当前逐篇完成69/107，结论会随全组比较修订；下文不是最终筛选。

首先必须拆开三条线。Self-Refine、Reflexion以及DeepVerifier主要修正同一道任务的输出。EvoTest能跨episode修改提示、温度、成功记忆和Python状态抽取器，范围确实更广，但50轮都重置同一游戏初态，作者明确承认特定实例策略可能因钥匙位置改变而失效。它们提供反馈与控制机制，不能替代跨任务可复用能力的证据。

Generative Agents、MemoryBank、MemGPT维护长期状态。前者递归抽象的是角色经历，后两者主要保存用户事实与分层上下文；这些状态能改善一致性、检索或个性化，但其更新规则固定，并未证明改进器或普遍任务能力持续增强。Generative Agents的消融是用完整系统同一轨迹积累的记忆作问答；MemoryBank缺无记忆/遗忘规则的受控定量消融；MemGPT的DMR基线仅有损摘要，而增强系统可搜完整历史，需说明访问条件。

Voyager则把成功行为存成可执行技能，并在新世界/新任务中调用，构成更明确的能力资产继承。其控制接口是Mineflayer高层动作，不能说解决低层视觉控制。Dynamic Cheatsheet将类似继承推广到跨查询的策略与代码；GPT4o的Game24成功主要来自存下一段通用Python求解程序。空memory同提示控制非常关键：某些提升来自工具鼓励提示而非持续学习，Claude在相同Game24几乎不提高。无GT自整理也会把错误放大。

ACE解决持久文本维护本身：整段重写会漏掉已有知识，ID化条目和delta合并减少这种损失。新增附录直接消融局部更新，AppWorld test-normal有/无incremental两指标均值70.3/56.9，baseline53.3。它与GEPA互补：GEPA用轨迹反思和样例级Pareto候选搜索高效模块提示；ACE更适合大量细粒度经验。两者优化器均固定。ACE的新成本表显示输入token低于GEPA但其“rollout”计数更高，旧表/新表配置与口径不可混报；测试阶段长playbook输入仍增117.4%。

SkillAdam进一步保留优化过程状态：issue tracker跨候选记录问题，gain波动EMA调下一轮编辑幅度，拒绝候选也能更新这些状态。这比仅保存最终技能更接近“记住怎样改进”，但它没有演化固定更新算法。COBRA-Skills以小MLP/LinearUCB选择和淘汰技能，回报统计及进化算子固定，代表资源配置互补路线；不能把冻结35B执行器说成训练了35B模型。

新技能系统应逐项核对实际变化对象。TROVE的工具图在测试前冻结，在线修改的是当前workflow后缀，没有跨任务库更新。SE-GoS能更新图关系、权重和node检索描述，但实验诱导的依赖边实际上为0，主要收益来自已有边回报重权；多轮也不单调。GUI技能演化有纵向日志与版本快照，但性能门控缺失、各domain单轨迹，后半程提升有时间顺序混淆。Who Maintains Agent Skills提供有价值的反证：真实人工维护版本在较充分的cross-family transfer实验中平均效果近零，而非默认维护即能力进步。

当前核心候选为Voyager、GEPA、ACE、SkillAdam；其余已读条目主要是历史机制、边界、负结果和较窄互补贡献。此列表无配额，待剩余记忆更新策略、技能进化与安全证据全部完成后再比较。


第19–29项进一步把“经验积累”和“学习记忆策略”区分开。ArcMemo主结果多来自预先归纳后冻结的记忆，在线版本只有允许两次重试时才显著更好；Agent KB确实共享跨领域经验，但三pass和无KB单pass不能混作同预算收益，其种子轨迹生成描述与附录给真值模拟经验的提示也需要交代。ExpSeek则把错误风险（token熵）映射到检索介入时机，记忆与阈值离线建立，在线改善不等于继续演化。

ALMA是新的核心节点：元代理直接生成更新、检索、存储逻辑的代码，验证并保留不同记忆设计；实际改变的是记忆算法而非只往库里写内容。它从ADAS与DGM式候选档案搜索继承设计，四域各自重新搜索，主结果多为收集后冻结部署，只有ALFWorld补充动态实验。因此可称自动发现记忆算法，不应说同一个系统无界改进自身。MiniHack优胜程序还内置BFS、行动掩码与硬编码环境先验，增益未完全拆分为记忆贡献。

PolySkill也保留为表示层核心：抽象目标接口与网站实现分离，组合函数可重绑定，未实现接口再引导探索课程。它将AWM与Voyager/ASI作为相关工作讨论，并明确扩展SkillWeaver的自提议探索概念，具有未见网站、在线目标域学习和多网站课程比较。跨域静态仍会退化；接口数量不计子类实现，技能调用按一步计，完整token高于无技能，不能把较短轨迹直接写成整体更省。其贡献是可继承能力资产的结构，不是改进器自改。

EFRE通过互不相容的新反馈分裂提示分支，避免整段提示修订覆盖旧能力，但优化器和路由器固定。EvoSkill把失败诊断与技能目录、脚本、提案历史相连，有SealQA→BrowseComp迁移，单标量top-k却称Pareto，且缺GEPA/等预算对照。AutoSkill主要证明能够抽取并合并1858张技能卡，没有行为收益评估；版本号不代表能力改进次数。SkillFlow则给出有用反证：11种配置中6升、4降、1平；GPT-5.3 Codex技能使用84.94%时成功率仍从52.41降至46.39，说明存取量、使用率与有效学习不能等同。

OpenSkill主要是针对同一道目标任务的外部研究、构造技能与重试，再转移给不同模型，未显示跨任务持续库。更关键的是附录F明确允许GT pass/fail bit触发加严测试，与正文“真值只用于最终评估”矛盾；独立验证器精确率56.9%、一致率60.7%，3轮后继续迭代反而退化。SkillClaw的跨用户共享机制值得记录，但单调六天曲线带有best-so-far选择：Search Night3和Safety Night4无任何新技能，仅同池重测得分更高。验证接受规则不能推出未来部署性能永不下降。

截至29项，核心候选为Voyager、GEPA、ACE、SkillAdam、ALMA与PolySkill；全组仍在读，后续比较可能调整。


第30–40项把机制进一步细化。MemSkill是技能内容与选择器的双层演化：小型PPO控制器学习从当前技能库选取操作，冻结LLM designer根据困难样本更新INSERT/UPDATE技能，新增技能还有短期探索质量。它确实变化了记忆管理技能，但不是训练70B执行器；正文v2三MLP、分割和新表必须覆盖旧结论。ALMA偏向直接搜索记忆算法代码，MemSkill偏向学习使用/修订记忆技能，两者互补。

MemRL的核心是经验级效用信用，而非仅相似度检索：先语义过滤再结合标准化效用，任务结果EMA写回每条被用经验。冻结记忆的跨任务测试比同题十轮更接近迁移证据；HLE全量反复运行和跨模型共享同题库应明确叫runtime memorization。其附录GEM式单调保证并不成立：以MSE校准Q未必让其所写J上升，实际top-k又不等于Boltzmann策略。核心地位依据实际信用分配机制与跨域实验，不依赖错误的无遗忘保证。

Growing Harness把优化对象扩到agent程序：trace DAG限制编辑到实际执行函数，失败窗口与固定验证集联合门控，并回滚代码和优化游标状态。这比单个技能文件更接近可审查的能力构建；200/50/50独立分割和随机重复评估也较清楚。它仍用冻结优化器，20B BigCodeBench没有收益，Web策略明显含确定性领域处理；Algorithm1的窗口内Q条件和Web K=4/Q=8不相容，应记录而非修饰掉。GEA则改变候选群的信息流，群内交叉借鉴tool/失败轨迹而非只沿单祖先；借鉴广度是新机制，$13k SWE成本与预设模型切换须交代，Polyglot百分数分母未明。

ForeDreamer可编辑经验、Python工具和工作流，但附录明确把validation前5候选全部送test并报告test最佳，不能作为严格独立留出成绩；当前列support。Agent-Pro作为早期互动策略提示优化有历史价值，但附录所谓Reflexion只做单步复查，不能据此宣称超越真实情节记忆基线。

诊断线应与能力积累线并行。EvoMemBench的回合内/跨回合×知识/执行四格有用：单任务上下文保持不等于能力学习，复杂记忆也不保证优于原始上下文。但其Table4 Vehicle64K成功率列与Table14 Gorilla64K进度列逐行相同，存在错列嫌疑；方法包装后的排名也不能自动当作原系统复现排名。跨类型冻结ALF经验可有显著负迁移，例如AgentKB Cool→Heat −40pp。

Library Drift/Ratchet将使用证据、可拒绝路由和淘汰显式化，过早退休破坏库是有用负结果；其无注入A1却不是无治理累积对照，c=2p−1也不是相对无技能的因果贡献，因此无发散保证和“治理修复漂移”的普遍归因过强。Blind Curator更进一步隔离判分腐败，区分真正贡献退休与容量淘汰：后者仍活跃会掩盖前者已停，而且最终成绩可能稳定。该研究诚实保留配对留出零结果，但45%阈值只属于固定Ratchet算术，对称噪声接近50%也并非保证生存。

Memory Reward Inflation提出经验自评污染可通过可信标签影响后续行为，SQL执行/退化/字面值检查仅降分就取得同生成预算+2.9pp，这是可保留的证据。它声称误差去相关是改善必要条件则不成立：verifier误差为原偏差一半时相关系数仍1，却能降低偏差。SSGM提供权限、不可变账本和定期重整概念，未实现或实测，其漂移界把成功重整直接作为前提。不能让理论包装替代已验证机制。

截至40项，新增核心是MemSkill、Growing Harness、GEA、MemRL；与已有Voyager、GEPA、ACE、SkillAdam、ALMA、PolySkill合计10项。筛选继续，不以比例控制。


## 信任边界与评价污染（第40—47项）

TAME把信用以自然语言注意事项呈现，但自身信任集并未一致改善，不能以“不训练模型”推出旧能力保存。Agent Skills综述有包装与治理框架价值，SKILL.md格式本身不是演化机制。

技能风险需要区分传播方向和证据单位。On Safety Risks从纯良性经验出发，在危险任务上观察更多执行；其中一部分只是格式/能力恢复，attention×gradient不足证明对齐内部因果。Practice Makes Unsafe反向研究恶意经历如何污染后续良性任务，干净会话只迁移技能文件及等预算全良性对照构成更直接的持久性证据，进入核心。但其URR只计显式选择，注入上下文也能传播；SafeEvolve的降低危害伴随效用损失，并非最优Pareto防御。

SkillJack补充派生来源问题：源轨迹删去，另存技能仍存在；所谓ASR大多是路由代理，而且A2S词汇检索库全为毒化项。EvoSkill Injection把攻击分成新建、升级和强化，跨模型有用，但允许伪造整个assistant成功历史，下游题按已存技能对齐，不能外推自然部署攻击率。MemEvoBench只测三轮，其workflow无记忆也会随轮次恶化，A-MEM的纠错工具部分配置更差；保留其压力测试用途，同时记录主文概括与附表的差异。

Trusting Trust Revisited是更直接的RSI交叉核心：投毒评分基准让SICA/Hyperagents把局部不安全做法变成长期指令，撤去投毒后仍保留；正常功能评价看不见漏洞，定向惩罚才能清毒。原DGM的通用性约束在本攻击下有抵抗作用，成功DGM版本是研究者主动改提示，不能称原生DGM被攻破。此文还报告并修复git历史暴露隐藏测试的漏洞，需与原论文结果边界分开。


## 从任务内工作记忆到可迁移流程（第48—57项）

EvoMemory把固定经验检索与运行时 ReMem 编辑放在同一流中比较，但失效经验对不同模型与任务方向不同；同序列累计曲线不能独自证明学习。LifelongAgentBench则用固定环境重置而保留历史来隔离跨题状态；长历史有时明显退化，分组投票减少每次输入长度却增加调用，不能直接说总推理更省。

EvoClinician把诊断最终反馈与过程动作信用连接，机制有用，但模拟患者填补缺失信息、测试资料缺失与行动效率混合，会让记忆学习数据可获得性的捷径；暂留支持。FORGE用群体成功记忆广播和毕业冻结形成跨情节积累，但去毕业有时更好；单一网络环境、负惩罚和成本表口径须保留。VASO将技能修改接到形式验证，然而标签映射本身未验证，满足性也不等于任意环境下安全。它补充验证反馈设计，不能用条件证明替代完整部署安全。

SkillOpt进入核心，因为不仅优化可移植技能，还把拒绝经验与优化器专用 meta-context 保留并用于后续改进；这比只写技能文件更接近改进过程的持久状态。双时间尺度、保守编辑与门控均是固定元算法。重要反证来自 Figure 3：LiveMath 验证分数持续升到约 0.825，测试却在早期约 0.62 后降到约 0.565，不能复述其“验证一直跟踪泛化”的文字。跨模型、跨 harness 技能迁移较有说服力，但 token 成本高、无等预算 optimizer 对照，电子表格还学会迎合静态值评分。

Self-Notes把工作笔记插入输入流，有细致 oracle、dummy note 与长度消融，但实际训练 GPT-2 小模型，且笔记不跨题继承，列小规模机制补充。ReadAgent是冻结模型的文档 gist 与按需回读，压缩资产可在同文档问题间复用，却不改善记忆策略；QMSum ROUGE、GPT-3.5 全文对照并非全面获益。CodeAgent则只有固定工具链和当题调试，符号导航信息贡献最大；在 RSI 主叙事里可由基础工具增强和 Voyager 对照覆盖，不单列详细核心。

AWM新增核心：离线冻结工作流与在线自归纳均有实验，并用每模板一个例子的子集排除最直接模板重放解释。它把抽象变量子程序作为逐步决策参考，清楚区分持久流程与可执行宏。规则归纳在 WebArena 与 LLM 归纳持平，直接宏使 Mind2Web 步骤成功提高但整任务下降，因此不把“更抽象、更自动运行”误当普遍更好。PolySkill后续解决接口与实现分离，比把这两者都称技能文件更能解释机制前进。

截至58项已完成逐篇阅读记录；14项核心、41项支持、2项小规模机制补充、1项冗余。计数以 JSONL 为准，后续仍需全部完成再综合筛选。


## 经验信用、成本与事实记忆的分界（第58—68项）

ReasoningBank进入核心：失败与成功都能被抽象成有查询适用条件的推理策略，MaTTS再把同题多轨迹比较接回记忆。其具体实现为追加，不是更新合并旧条目；“同一记忆不断进化”的案例措辞不能覆盖这一事实。失败经验对比AWM/Synapse、随机pass@1与BoN选择分别提供不同证据；oracle pass@k不能与部署成功率混用。更多检索记忆显著变差，MaTTS的五倍轨迹预算也不能隐藏在单轨迹平均成本之后。

PRIME只有按问题难度在快慢推理之间路由，记忆回顾实为静态外部医疗语料检索，没有跨任务状态改进，剔除出RSI范围。Thought Retriever把查询答案再次写成知识，存在持久状态，但摘要任务的问题生成读取了目标摘要，oracle检索和“confidence=确实给出答案”均不能充当可靠性验证。小幅预填充记忆迁移结果值得保留，尚不足证明新缩放规律。

EvoNote把社区注释写作、反事实式自评措辞和phase-trigger策略接成持续流；细粒度信用实际是固定LLM诊断，不是受控因果归因。HealthJudge虽在前序工作训练，本系统固定，路线仍是Harness。后期低信息帖测试及人工偏好说明有应用价值，但没有相同记忆内容去phase触发的独立消融，策略更新器也不变化。

MobileGPT把可复用手机路径参数化，特别清楚地展示人类纠错如何成为持久能力来源：无人工的主比较暖启动82.16%略低于冷82.70%；98.75%来自另一套先人工修复冷路径的实验。成本改善仍有意义，但不应将正确路径重放解释成无人干预的能力增长。

SCM、H-MEM、Mem0、Zep、SGMem沿着另一条线发展：从按需激活/摘要选择，到层级索引、事实增改删、双时间有效性、句子图检索。其状态保存和更新确实持续，但目标主要是事实记忆与查询效率。Mem0全上下文72.90高于事实库66.88及图版68.44；图版的多跳分数还从51.15降到47.19。Zep在115k历史上得到更好的查询折中，然而双时间字段的独立作用未消融。H-MEM只与FAISS Flat检索效率比较。SGMem在LoCoMo零跳最好，完整历史仍稍高于其最佳图配置。不能从结构名称或更新次数推导自改进程度。
