## [007] STOP

**位置：** Harness / 已核对重点案例。机制和回流已核对，纳入重点案例；不等于所有递归主张均已证明。

**团队：** Microsoft Research / Stanford / OpenAI（研究在微软期间完成）

**改变与回流：** 用调用冻结 GPT-4 的改进程序修改该改进程序自身。。改进程序产生后继；后继继续生成程序改进。

**原理与操作：** 用调用冻结 GPT-4 的改进程序修改该改进程序自身。

**最值得保留的贡献：** 把“更好的解”推进到“更好的产生改进的程序”。

**证据：** 作者报告后继改进程序在受限算法任务上优于种子，包含跨任务检验。

**规模：** GPT-4 冻结；改进器代码可变；算法任务与规定调用预算。

**边界：** 任务规模有限；作者也未称为全部组件均可改的完整 RSI。

**研究含义：** 把“更好的解”推进到“更好的产生改进的程序”。

**定位：** [首页署名与脚注；§3–4、Algorithm 1、迁移实验](https://arxiv.org/pdf/2310.02304v3)；方法/证据摘读，未声明完整逐页审核。

## [011] Self-Rewarding LM

**位置：** Model / 已核对重点案例。70B 的回答与自奖励参数共同继承；外部训练程序固定。

**团队：** Meta / NYU

**改变与回流：** 同一模型的回答/评价权重；每轮偏好数据。M1 生成回答与偏好训练 M2；M2 再生成偏好训练 M3；出题模型固定。

**原理与操作：** 同一 70B 模型产生回答并评分；每轮构造偏好对，以 DPO 更新下一代，再由下一代生成回答与偏好。

**最值得保留的贡献：** 把回答者与奖励者放进同一参数继承链；主要贡献在学习信号及其迭代，而非修改 agent 软件。

**证据：** 核对 §2–3：M1 为种子 SFT，M2/M3 为两次 DPO；另评指令跟随与奖励排序，并比较仅正例 SFT。

**规模：** Llama 2 70B；两轮偏好集分别 3,964 / 6,942 对；256 题成对比较与 805 题 AlpacaEval 2。

**边界：** 实际新题由固定 Llama 2-Chat 70B 生成；有人类种子、外部评审和早停。不证明无外部信息或无限递归增长。

**研究含义：** 区分轮间新数据与轮内固定数据优化；评价能力提高仍须以独立目标检验。

**训练说明：** 后训练；种子 SFT → 迭代 DPO；轮间在线生成偏好；每轮 DPO 优化已收集的偏好对，不等于 PPO 在线 RL。；一次种子 SFT + 两轮 DPO

**定位：** [§2.1–2.4，§3.1–3.2；特别是 §3.1.3 的固定出题模型。](https://arxiv.org/html/2401.10020v1)；方法/证据摘读，未声明完整逐页审核。

## [015] SICA

**边界：** 不能把子集分数说成完整 SWE-bench 成绩；未证明后继改进效率持续增长。

**研究含义：** 执行者与改进者共享可编辑实现；成本和速度也进入选择。

**定位：** [首页；§3、Algorithm 1；§4 与 Appendix D](https://arxiv.org/html/2504.15228v1)；方法/证据摘读，未声明完整逐页审核。

## [016] DGM

**位置：** Harness / 已核对重点案例。已定位的改动在外部软件/状态；未训练基础模型权重。

**团队：** Sakana AI / UBC / Vector Institute

**改变与回流：** 执行代码、工具及代理实现。保留候选代理并用于后续代码改进；不等于已证明改进速度持续增长

**原理与操作：** 智能体修改自身代码，保留多个历史分支，再由选中的后继继续修改。

**最值得保留的贡献：** 可运行的自修改与开放谱系结合；较差的中间节点仍可能成为有价值的祖先。

**证据：** 比较固定改进者、去掉谱系档案等设置，并报告跨模型与编码任务迁移。

**规模：** 冻结基础模型；80 次进化；SWE-bench 与 Polyglot，采用分阶段任务子集评价。

**边界：** 开放搜索的收益仍受评估次数、选择集和基座能力影响；未证明无限增长。

**研究含义：** 我们的状态必须包含谱系和复用路径；只跟踪当前最好分数会丢失未来价值。

**定位：** [§3–4，尤其 §4.2–4.4 与谱系图](https://arxiv.org/html/2505.22954v3)；方法/证据摘读，未声明完整逐页审核。

## [021] HyperAgents

**位置：** Harness / 已核对重点案例。已定位的改动在外部软件/状态；未训练基础模型权重。

**团队：** Meta / UBC / Vector / Edinburgh / NYU

**改变与回流：** 任务代理与元代理的共同代码。后继的可编辑元代理继续提出改动；主要父节点选择仍由外层设定

**原理与操作：** 任务代理和修改代理位于同一可编辑程序，元层诊断与修改流程也能被改写。

**最值得保留的贡献：** 相对固定修改提示，把生成改进的方法开放给经验选择。

**证据：** 包含冻结元代理、去掉档案等对照，以及跨域元层迁移；主实验父代选择仍固定。

**规模：** 编码、论文评审、机器人奖励设计、数学评分；冻结基础模型，多域代理实验。

**边界：** 可表达任意程序不等于能有效发现任意改进；不同领域评价可信度不同。

**研究含义：** 改进者是可学习的角色，不必添加一个永远固定在系统外的模块。

**定位：** [§3–5；§4.1 对照；Appendix D / E 元层变化](https://arxiv.org/html/2603.19461v1)；方法/证据摘读，未声明完整逐页审核。

## [032] RRSI

**位置：** Harness / 已核对重点案例。已定位的改动在外部软件/状态；未训练基础模型权重。

**团队：** Google Cloud AI Research / Stanford / Washington University / UNC

**改变与回流：** 提示、控制流、工具与上下文机制。限制候选改动并筛掉过拟合/昂贵改动，保留到未见任务

**原理与操作：** 对修改提案与接受环节施加约束，防止任务特化和运行成本膨胀。

**最值得保留的贡献：** 把外部迁移与使用成本纳入选择，而不是只追求进化集最高分。

**证据：** Table 2 中无约束搜索进化分更高，RRSI 的 OOD 均值更高且 token 更少。

**规模：** 冻结基础模型、有限进化任务；报告百万 token / trial；仓库保留表格算术。

**边界：** 这是作者聚合表上的比较，尚无独立重跑和完整多重比较不确定性分析。

**研究含义：** 修改空间与接受规则必须分开；训练分提高可能与可迁移价值背离。

**定位：** [Table 2；提案 / 接受约束及消融](https://arxiv.org/html/2609.24972v1)；方法/证据摘读，未声明完整逐页审核。

## [036] MASS

**位置：** Model × Harness / 已核对重点案例。27B 模型与多智能体工作流均更新，已报告两轮。

**团队：** Sakana AI / UC Berkeley

**改变与回流：** 工作流角色与信息路由 + 同一 27B 模型权重。当前模型演化工作流，执行轨迹用于 SFT，更新模型再次担任执行/优化/评价角色。

**原理与操作：** 进化多代理工作流，再用其中的轨迹训练共享模型，重复使用于执行、优化和评价角色。

**最值得保留的贡献：** 将外部协作过程内化到同一模型；公开比较训练 token 和跨域表现。

**证据：** 两轮更新；公开研究任务部分提升，Terminal-Bench 与 SWE-bench 同时出现回退。

**规模：** Qwen3.6-27B；8 个训练任务，6 个公开测试基准；各任务与重复次数单列。

**边界：** 共享权重可能共享偏差；训练 token 对齐不等于总成本对齐或广泛正迁移。

**研究含义：** 协同演化可能重新分配能力；必须保存回退，而不能只画上升曲线。

**训练说明：** 后训练；工作流进化搜索 + SFT；每轮由当前模型与工作流采集轨迹；训练阶段做 SFT。；2 个交替周期；非同时异步训练

**定位：** [§3–4；Appendix C 轨迹与 SFT；Appendix C.5 跨基准回退。](https://arxiv.org/html/2610.12176v1)；方法/证据摘读，未声明完整逐页审核。

## [039] HGM

**位置：** Harness / 已核对重点案例。已定位的改动在外部软件/状态；未训练基础模型权重。

**团队：** KAUST

**原理与操作：** 用一个分支的后代表现估计其继续研发价值，分开选择扩展与追加评估。

**边界：** 自适应后代采样有选择偏差；oracle 命题不能转成实际估计器的无条件最优性。

**研究含义：** 未来继续研发的价值必须单独估计，不能以当前任务分数替代。

## [062] Self-Taught Evaluators

**位置：** Model / 已核对重点案例。实际训练 70B 评价器；属于评价角色的模型更新。

**团队：** Meta FAIR

**改变与回流：** 评价模型权重；合成判断训练集。上一轮评价器生成下一轮判断；每轮学生从同一原始种子重新微调，而非连续接着上轮权重训练。

**原理与操作：** 用构造偏好和合成判断训练评价器，再以更新的判断生成训练信号。

**最值得保留的贡献：** 学习如何评价，同时保留构造标签这一外部来源。

**证据：** 核对种子模型、构造标签与迭代过程；每轮学生从初始种子重新训练。

**规模：** Llama3-70B-Instruct 种子，Mixtral 辅助数据，RewardBench 等评价。

**边界：** 并非无锚定自证，也不是每轮直接继续微调；标签构造可能有误。

**研究含义：** 评价器可演化，但真值来源、初始化和误差传播必须显式记录。

**训练说明：** 后训练；SFT / 判断文本负对数似然；轮间刷新合成判断，轮内固定数据批次；构造偏好标签提供锚点。；5 轮；生成与训练交替

**定位：** [§3.3–3.5、§4.1、§5–6；70B 与种子重置在 §4.1。](https://arxiv.org/html/2408.02666v1)；方法/证据摘读，未声明完整逐页审核。
