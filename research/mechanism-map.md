# Per-work mechanism map

All 67 current corpus entries are included. These are our conditional mechanism
interpretations and proposed interventions, not new empirical claims about each work.
A star marks primary methods/results read in the mechanism passes; other rows retain the prior
source-review boundary. New frontier entries have exact review scopes in data/mechanisms.json.
Source reports and our judgments are separated in EVIDENCE.md and FRONTIER_COVERAGE.md.

| Work | Causal operation | Condition or failure | Separating intervention |
|---|---|---|---|
| [Speculations Concerning the First Ultraintelligent Machine](https://doi.org/10.1016/S0065-2458(08)60418-0) | Reuse of improved design operations can increase future design yield. | The feedback coefficient and resource costs are unspecified; positive feedback need not outrun difficulty. | Instantiate a design operation, pin its ancestor and compare continuation yield. |
| [EURISKO](https://www.cs.northwestern.edu/~mek802/papers/not-mine/Lenat_EURISKO.pdf) | Retained heuristics alter which future hypotheses are generated and pursued. | Useful edits must remain expressible in the heuristic representation and interpretable by its runtime. | Freeze meta-heuristics while giving both arms the same discovered object-level rules. |
| [Gödel Machine](https://arxiv.org/abs/cs/0309048) | A proof can authorize a change by comparing future utility, including continued proof search. | The relevant claim must be provable in the axioms and discoverable within available resources. | Hold utility and axioms fixed; compare rewrite availability under different proof-search allocations. |
| [MAML](https://proceedings.mlr.press/v70/finn17a.html) | Initialization shapes the effect of a later task-specific gradient update. | Source and target adaptation geometry must align; a good initial score alone is insufficient. | Compare initializations with matched initial task score under the same adaptation examples and steps. |
| [AlphaGo Zero](https://www.nature.com/articles/nature24270) | Search improves behavior; self-play supplies consequences; policy/value training amortizes this computation. | Search quality, imitation error and the evolving opponent distribution jointly matter. | Match search calls and independently vary search-target quality and training fit. |
| [AutoML-Zero](https://proceedings.mlr.press/v119/real20a.html) | Program mutation and selection discover reusable learning procedures. | The primitive language, task distribution and evolutionary search determine accessible algorithms. | Change the primitive representation while fixing evaluation and total search budget. |
| [STOP](https://github.com/microsoft/stop) | An improver edits an executable improver, potentially retaining better candidate-generation operations. | The edit must improve future output distributions rather than only the currently edited target. | Run old and revised improver programs on identical external target copies. |
| [Promptbreeder](https://proceedings.mlr.press/v235/fernando24a.html) | Mutation prompts alter the proposal distribution used to evolve task prompts. | A better task prompt need not be a better mutation instruction on other targets. | Cross mutation-prompt versions with a fixed panel of task prompts. |
| [FunSearch](https://www.nature.com/articles/s41586-023-06924-6) | A language prior proposes programs; executable scoring and an archive retain useful discoveries. | Evaluation must represent the intended property and the representation must expose useful programs. | Remove evaluator detail or archive diversity separately, matching generated candidates or compute. |
| [SPIN](https://github.com/uclaml/SPIN) | Training contrasts generated responses with a reference data distribution and changes later response probabilities. | The reference data are an anchor; this is not unfiltered self-copying. | Replace reference responses by draws from the current model while holding the optimizer fixed. |
| [Self-Rewarding Language Models](https://proceedings.mlr.press/v235/yuan24d.html) | Self-generated preferences reweight the training target; learning changes both answer and judgment behavior. | Judge-answer dependence can retain systematic errors even when internal reward increases. | Pin the judge while updating the answerer, then reverse the intervention on the same candidates. |
| [Gödel Agent](https://github.com/Arvid-pku/Godel_Agent) | Self-edited control logic changes accessible actions and the way feedback is used. | Arbitrary editability does not imply positive proposal or transfer quality. | Transplant the retained code change across unchanged target models and tasks. |
| [ADAS](https://github.com/ShengranHu/ADAS) | A fixed designer conditions architecture proposals on an archive of previous designs and outcomes. | Target-agent gains can arise without any learned change to the designer. | Reset or shuffle archive information while retaining the same designer and search budget. |
| [AFlow](https://github.com/FoundationAgents/AFlow) | Tree search allocates trials among workflow designs and composes available operators. | Search efficiency depends on branching, feedback and the expressiveness of workflow operators. | Hold operators fixed and replace tree allocation by equal-budget flat search. |
| [SICA](https://github.com/MaximeRobeyns/self_improving_coding_agent) | Code and tool changes can reduce execution failures and improve useful work per budget. | A local repair may not improve successor production or transfer outside its failure mode. | Replay matched failure states through ancestor and successor tools before a common-target actor test. |
| [Darwin Gödel Machine *](https://github.com/jennyzzt/dgm) | Reusable coding operations and retained alternative parents change subsequent proposal opportunities. | Archive cost and target difficulty can confound the benefit of successor reuse. | Cross pinned/refreshed actor with archive/last-parent policies on common starting targets. |
| [GEPA *](https://github.com/gepa-ai/gepa) | Trace-conditioned reflection localizes repairs; instance-specialist parents preserve alternative solutions. | Diagnostics must contain usable information, and specialist branches must justify their cost. | Return the same final score but remove diagnostic content; separately replace specialist selection by greedy selection. |
| [AgentBreeder](https://arxiv.org/abs/2502.00757) | Evolution changes coordination and communication among component agents. | Extra roles can add redundant errors and overhead rather than independent information. | Match total calls and change routing while holding component models and candidate counts fixed. |
| [On the Statistical Limits of Self-Improving Agents](https://arxiv.org/abs/2510.04399) | The reachable hypothesis class and feedback sample determine what generalization can be learned. | Its stated capacity and sampling assumptions cannot be discarded when applying the bound. | Vary reachable policy capacity and sample size within the theorem's task assumptions. |
| [SEAL *](https://github.com/Continual-Intelligence/SEAL) | Self-edit generation is trained on utility after the learner consumes that edit. | Teaching value depends on learner state; old edit rewards can become stale. | Compare current-learner rewards with stale rewards for the same edit pool and adaptation budget. |
| [HyperAgents *](https://github.com/facebookresearch/HyperAgents) | Editable meta code changes diagnosis, proposal and reuse, with task and meta roles sharing a program. | Transfer requires reusable improvement operations, not merely source-domain facts. | Transfer meta code to new task-agent initializations while preserving the target evaluation interface. |
| [Harness Updating Is Not Harness Benefit *](https://arxiv.org/abs/2605.30621) | Proposal competence and ability to execute the proposed computation are distinct causal factors. | Weak executors may not follow a harness; strong executors may have less recoverable headroom. | Cross creator and executor versions and measure adherence as well as final score. |
| [SIA](https://github.com/hexo-ai/sia) | Feedback directs updates to code or weights, changing execution and later learning data. | Different update surfaces may repair different bottlenecks and interfere on other tasks. | Apply matched model-only, harness-only and combined changes with crossed execution. |
| [Recursive Harness Self-Improvement](https://arxiv.org/abs/2607.15524) | Workflow specifications condition information flow and are revised from outcome comparisons. | A weak proposal distribution can bottleneck progress even under improved evaluation. | Replace proposer and evaluator separately with the executor fixed. |
| [Rethinking the Evaluation of Harness Evolution for Agents](https://arxiv.org/abs/2607.12227) | Task-time search and persistent harness changes compete for the same resource budget. | A persistent update only amortizes if reused enough and still relevant. | Vary future reuse count and include development cost in the comparison. |
| [Co-Evolving Harnesses and Model Weights for LLM Agents *](https://arxiv.org/abs/2607.22688) | Diagnosed runtime failures guide harness repairs that change subsequent model-training experience. | Schema, memory and middleware fixes differ from weight-level skill acquisition. | Preserve final rewards while hiding failure localization; compare training on repaired versus original traces. |
| [HELIX *](https://github.com/HKUDS/HELIX) | Harness variants yield both task outcomes and contrasting records potentially useful for learning. | Portfolio coverage and record count do not measure post-update student improvement. | Train matched students from competing harness sources with decision inputs and task mixtures controlled. |
| [HSI](https://github.com/TailinZhou/hsi) | Meta-evolver changes can alter the distribution and allocation of future harness edits. | Meta-level code change may overfit the particular improvement problem. | Move only the meta-evolver to new target harnesses under matched budgets. |
| [EvoHarness-RL](https://arxiv.org/abs/2608.05446) | Learned coordination changes when external state is written, retrieved and used. | External support can become redundant or harmful as policy competence changes. | Cross policy checkpoints with fixed external-state interfaces and measure redundant operations. |
| [Auditing Harness Tampering in Self-Improving Agents](https://arxiv.org/abs/2609.00069) | Changing the measurement path can increase observed score without improving intended utility. | Selection covariance with true utility can become nonpositive. | Recompute outcomes through an independently preserved measurement path. |
| [HarnessDev](https://arxiv.org/abs/2609.01437) | Creator search changes executable scaffolds consumed by a potentially different executor. | A creator's design can exceed the executor's interface-following capacity. | Run a creator-by-executor matrix at fixed runtime budgets. |
| [RRSI *](https://github.com/google-research/rrsi) | Proposal and acceptance constraints favor transferable, affordable edits over source-score fitting. | Edit size alone is not the mechanism; overly restrictive search can also exclude useful changes. | Hold a candidate pool fixed to separate acceptance effects from changes to proposal distribution. |
| [Meta-Harness](https://github.com/stanford-iris-lab/meta-harness) | Search changes which information is stored, retrieved and exposed to a fixed model. | Interface changes must preserve decision-relevant inputs and avoid costly irrelevant context. | Replay histories through competing context policies while matching model calls and task distribution. |
| [AIDE² *](https://arxiv.org/abs/2609.26457) | Search and memory rewrites improve the inner research agent under a fixed main outer proposer. | A stronger research target need not beat the original outer proposer at producing later agents. | Separate equal-call memory/search comparisons from the common-target outer-agent ignition test. |
| [OpenRSI *](https://github.com/FrontisAI/OpenRSI) | Execution-grounded training improves shared program-editing operators used by long-horizon search. | Operator competence and search allocation both contribute and can saturate separately. | Cross trained/base operators with fixed/changed search control on held-out research tasks. |
| [MASS *](https://github.com/SakanaAI/mass) | Workflow-conditioned trajectories train shared weights used in solving, proposing and judging. | Training value depends on retained inputs and task alignment; correlated errors can persist. | Hold teacher quality approximately fixed while altering context preservation and source-task weighting. |
| [RSI-Anything](https://github.com/Gen-Verse/RSI-Anything) | Interaction and world-model predictions guide updates in an environment. | Simulated utility must predict external consequences; model error can steer search incorrectly. | Compare predicted and actual update rankings on interventions not used to fit the world model. |
| [Dream-RSI](https://github.com/zhengkid/Dream-RSI) | Replayed discovery trees train exploration choices before expensive online research. | Historical branching support and changed task dynamics limit off-policy transfer. | Evaluate exploration policies on new live branches with replay cost counted. |
| [Huxley–Gödel Machine (HGM) *](https://arxiv.org/abs/2510.21614) | Descendant-informed allocation estimates future branch value instead of current score alone. | Adaptive descendant sampling can bias the estimate; larger clades have unequal opportunity. | Predict later, unobserved branch outcomes under equal continuation budgets. |
| [Agentic Context Engineering (ACE)](https://arxiv.org/abs/2510.04618) | Persistent contextual lessons alter later decisions without changing weights. | Destructive compression or missing prerequisites can erase useful distinctions. | Compare incremental retention against full rewriting with the same new experiences and context cap. |
| [AlphaEvolve](https://arxiv.org/abs/2506.13131) | Executable search can improve algorithms or infrastructure reused by later model development. | Feedback through infrastructure depends on real deployment and resource savings, not the label of the target. | Measure downstream work completed under the same physical resource budget before and after adoption. |
| [Optimization by PROmpting (OPRO)](https://arxiv.org/abs/2309.03409) | The optimizer conditions proposals on a history of candidate-value pairs. | History is useful only insofar as it predicts better candidates within the new target problem. | Compare true, shuffled and reset histories with the same model and evaluation allowance. |
| [Learning to learn by gradient descent by gradient descent](https://arxiv.org/abs/1606.04474) | A learned update rule exploits structure shared among training optimizees. | Meta-training distribution and recurrent state affect transfer and stability. | Hold optimizee initialization fixed and change optimizer weights on unseen loss geometries. |
| [Paired Open-Ended Trailblazer (POET): Endlessly Generating Increasingly Complex and Diverse Learning Environments and Their Solutions](https://arxiv.org/abs/1901.01753) | Environment generation and cross-environment transfer create alternative learning paths. | Transfer must connect useful states; environmental novelty alone is insufficient. | Remove cross-environment transfer while preserving total optimization work. |
| [Tasks, stability, architecture, and compute: Training more effective learned optimizers, and using them to train themselves](https://arxiv.org/abs/2009.11243) | A learned optimizer can execute the updates that train another optimizer. | Longer horizons can shift state distributions and stability beyond its training regime. | Cross optimizer versions, clipping rules and training horizons on common optimizer targets. |
| [STaR: Bootstrapping Reasoning With Reasoning *](https://arxiv.org/abs/2203.14465) | Correctness-filtered rationales and answer-conditioned rationalization alter the learning target. | Hints can expose solutions but training must support inference without those hints. | Separate rationalization, filtering and per-task sample balancing at equal generation cost. |
| [Beyond Human Data: Scaling Self-Training for Problem-Solving with Language Models *](https://arxiv.org/abs/2312.06585) | Reward-weighted sampling and likelihood projection alternate as an approximate EM procedure. | Approximate learning, rare success and changed task weights can prevent practical improvement. | Compare pooled filtering with per-task-balanced filtering and measure projection error. |
| [Thinking Fast and Slow with Deep Learning and Tree Search *](https://arxiv.org/abs/1705.08439) | A planner supplies targets to a policy that guides later planning. | Search advantage must survive learning and shared task structure. | Freeze the policy used by search while training otherwise identical learners. |
| [DreamCoder: Bootstrapping Inductive Program Synthesis with Wake-Sleep Library Learning *](https://www.neurosymbolic.org/papers/EllisWNSMHCST21.pdf) | Library abstraction changes the search language while a recognition policy guides its use. | Shorter expressions help only if abstraction and execution costs are worthwhile. | Hold either the learned library or recognition policy fixed across cycles. |
| [Selecting Computations: Theory and Applications *](https://arxiv.org/abs/1207.5879) | Compute is spent where information can change the selected action. | Selection overhead and multistep information complementarity affect stopping. | Charge probe cost and compare metalevel selection with fixed allocation. |
| [Single-Agent Policy Tree Search With Guarantees *](https://arxiv.org/abs/1811.10928) | Depth divided by path probability controls search order and bounds effort. | Solution support, deterministic verification and admissible pruning are required. | Hold the tree fixed and change the learned probability of successful paths. |
| [Policy-Guided Heuristic Search with Guarantees *](https://arxiv.org/abs/2103.11505) | A heuristic and a policy jointly prioritize paths with bounded search loss. | Heuristic assumptions and node-dependent loss matter. | Cross the same policy with changed heuristics under measured expansion costs. |
| [Levin Tree Search with Context Models *](https://www.ijcai.org/proceedings/2023/0624.pdf) | A convex context policy learns from successful paths using a search-effort loss. | Fixed-path convexity does not establish global bootstrap convergence. | Compare imitation and bound objectives, and frozen versus reused collection policies. |
| [OpenAI o1: Learning to reason with LLMs](https://openai.com/index/learning-to-reason-with-llms/) | Policy learning changes the distribution of reasoning trajectories and the value of later inference. | Train/test compute scaling does not identify a self-improving research process. | Cross policy checkpoints and inference budgets; separate extra training from extra sampling. |
| [DeepSeek-R1](https://arxiv.org/html/2501.12948v1) | Sampling, reward-weighted policy updates and subsequent data production jointly change the learning distribution. | A fixed trainer is compatible with self-generated learning, but the paper does not establish indefinitely improving research ability. | Freeze collection policy or generated data while matching training and generation cost. |
| [Qwen3 Technical Report](https://arxiv.org/html/2505.09388v1) | A learner-generated state distribution and teacher targets interact with capacity and reasoning budget. | Teacher-provided information and small-model efficiency do not establish teacher-free recursive discovery. | Compare on-policy and off-policy targets for the same teacher/student pair and full data-generation budget. |
| [AlphaProof](https://www.nature.com/articles/s41586-025-09833-y) | Verification supports reusable proof learning while generated variations alter the curriculum. | Formal proof correctness is conditional on the formal statement; it does not establish fidelity of every autoformalization or broad research recursion. | Cross the prover and curriculum snapshots; independently check statement fidelity. |
| [MuZero](https://arxiv.org/abs/1911.08265) | Task-relevant dynamics learning changes both planning and the experience used for future updates. | Planning within an imperfect learned model differs from search in a known exact environment. | Cross world-model versions and planning budgets, measuring model error on visited states. |
| [Open-Ended Learning Leads to Generally Capable Agents (XLand)](https://arxiv.org/abs/2107.12808) | Task generation changes the learnable frontier and population transfer changes reachable skills. | Broadness within a constructed environment space is not unrestricted real-world generality. | Ablate adaptive task generation and population transfer separately at matched resources. |
| [SIMA 2](https://deepmind.google/blog/sima-2-an-agent-that-plays-reasons-and-learns-with-you-in-virtual-3d-worlds/) | Tasks, estimated rewards and visited states jointly determine the training distribution. | The official self-improvement report does not show that Genie itself recursively improves or that physical-world transfer is established. | Freeze task generator or reward model separately and test on independently assessed games. |
| [Constitutional AI](https://arxiv.org/abs/2212.08073) | Feedback production can be delegated to AI while the objective and calibration remain external. | The normative target remains externally specified; AI feedback is not automatically accurate or independent. | Hold principles and learner fixed while changing the feedback source and independent assessment. |
| [Self-Taught Evaluators](https://arxiv.org/html/2408.02666v1) | Better judgment generation changes the usable training pool for later evaluator versions. | Constructed preference labels can be imperfect; the student is reset to the seed each round rather than simply continuing fine-tuning. | Cross generation/evaluator checkpoints on fixed response pairs and separately validate constructed labels. |
| [Eureka](https://arxiv.org/abs/2310.12931) | A proposed artifact is valued by the learning process it induces, not only by immediate execution. | Useful reward optimization does not establish that the LLM reward designer itself becomes a stronger designer. | Compare rewards using equal policy-training budgets and transfer to untouched tasks or dynamics. |
| [Co-Scientist](https://arxiv.org/abs/2502.18864v2) | Search supplies hypotheses whose true value requires delayed external experimentation. | Internal hypothesis rankings are not scientific truth; validated hypotheses do not alone prove an improved research policy. | Compare internal rankings with prospective external experimental outcomes and later research choices. |
| [GPT-Red](https://cdn.openai.com/pdf/gpt-red-automated-red-teaming-via-self-play-at-scale.pdf) | Changing opponents generate a moving learning frontier; population diversity can prevent narrow adaptation. | Task-specific robustness improvement and co-training do not establish unrestricted recursive research acceleration. | Use the reported fixed-attacker controls and cross-checkpoint matrices, then compare held-out defender training. |
| [Automated Alignment Researchers: mitigating alignment failures](https://www.anthropic.com/research/automated-researchers-mitigate-alignment-failures) | A research policy chooses interventions whose value is measured after target-model training. | Improving target models does not show that the researcher improves itself; production data-efficiency claims are not full research-cost ratios. | Hold target initialization/budget fixed and compare research-agent versions across withheld training problems. |
| [Seed for Seed (Seed2.1)](https://seed.bytedance.com/en/blog/seed2-1-officially-released-advancing-ai-productivity) | Useful model-development outputs can feed later model development through several operational paths. | A deployment report supports use in AI development, not an identified causal multiplier or autonomous closed-loop growth. | Trace adoption and compare complete research work at fixed compute and human input. |

The next research question is which of these conditions is shared across tasks
and predicts interventions, not how many entries can be assigned a label.
