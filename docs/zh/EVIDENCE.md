# 公开证据与研究判断

[English](../../EVIDENCE.md) · [中文入口](../../README.zh-CN.md)

本文按实际机制和证据评价工作。科学价值与 RSI 标签是两回事；重要的局部成果也可能尚未支持更强的递归结论。

## 1. 怎样判断一次更新

对 $S_t\rightarrow S_{t+1}$，依次检查：

1. 改变的是回答、提示、记忆、工具、源码、权重、优化器、评价器，还是改进器？
2. 修改来自系统自身、固定强模型、人工工程、搜索，还是测试反馈？
3. 什么跨当前任务保留，形成了可版本化后继？
4. 收益迁移到哪些独立数据、新任务、领域、模型或环境？
5. 父代是否得到相同推理、搜索、训练与评价资源？
6. 哪些任务能力、成本、延迟、可靠性或校准发生回退？
7. 后继是否在新的改进问题上，比父代更善于产生下一代？

前六项可以支持不同程度的自改进；第七项直接检验本项目采用的递归条件。

## 2. 历史分支建立了什么

| 工作 | 已有贡献 | 尚待解决 |
|---|---|---|
| Good | 机器设计能力可能形成正反馈的定性论证 | 可执行更新、增长规律、评价稳定性与加速条件 |
| EURISKO | 在人工表示中生成和修改影响后续搜索的启发式 | 可扩展迁移、现代复现、参数学习与改进器持续提升 |
| Gödel Machine | 在公理、效用和证明要求下形式化自指重写 | 现实系统中可行的有用证明搜索 |

历史重要性应与现代系统的经验能力分别描述。

## 3. 相邻但关键的机制

**元学习与自博弈。** MAML、AlphaGo Zero 等说明跨任务塑造学习行为和自生成经验可以获得能力。目标、更新算法与接受规则通常仍由外部规定；它们为后继改进研究提供基础。

**AutoML 与算法搜索。** AutoML-Zero、FunSearch、AlphaEvolve 自动化算法发现，产物可以很有价值。固定优化器改进外部目标，与优化器自身变得更强，是不同实验对象。

**提示、工作流与代理搜索。** ADAS、AFlow、GEPA、AgentBreeder、OPRO 等发现更好的配置。其结论深度取决于是否持久保留、是否独立迁移，以及后继是否改善下一次更新。D0–D4 是本项目的论证层次，不是按项目名字固定分级。

## 4. 直接的现代证据

### STOP 与 Promptbreeder

STOP 改进可执行改进程序；Promptbreeder 同时演化任务提示和产生变异的提示。两者把部分更新机制纳入搜索，提供有界自指研究。

### Gödel Agent 与 SICA

代码可编辑使父代—后继关系具体可追踪。评价需结合任务集中程度、固定模型、代数与跨模型迁移；它们建立了持久程序自修改的路线。

### DGM 与 HGM

DGM 保留开放谱系，使当前非最优分支仍可能成为有用祖先；HGM 根据后代潜力分配搜索。检验谱系价值时，应控制候选数、评价接触量和总成本，区分更好的分配与更多计算。

### HyperAgents 与 HSI

两者将元层程序放入可编辑范围。[HyperAgents](https://arxiv.org/html/2603.19461v1)用 imp@k 直接检验跨领域改进能力：短预算迁移结果为正，较长循环的复利比较未达到统计显著。HSI 的 Harness 与 evolver 更新应按其自身迁移实验判断，不能合并成一个结论。

### AIDE²

[AIDE²](https://arxiv.org/html/2609.26457v1)在固定外层研究者下反复改进研究代理，并在外部 AI 研发基准上报告迁移。另行进行的 ignition 实验比较后继能否接管外层：每组 3 个种子，最终均值 0.780 与 0.782，结果不确定。已有证据支持研究 Harness 改善，尚未确认接管提高了改进效率。

### RRSI、Meta-Harness、RHI 等

这些工作在冻结模型周围产生可检查的系统改进。RRSI 研究编辑大小、特化、评价噪声、token 成本与剪枝；Meta-Harness 搜索源码；RHI 根据轨迹修订规格。关键适用条件是模型和任务的可迁移性，以及收益是否伴随额外资源。

### Harness Updating Is Not Harness Benefit

该研究把“产生有用更新”和“执行时利用更新”分开测量。基座更强与收益更大之间并非简单单调关系，因而需要区分 evolver 与 executor，测量跨模型矩阵及规模曲线。

## 5. 参数层自改进

**SPIN 与迭代自训练**展示固定训练规则下与前代交互产生的参数提升。长期问题是经验是否持续携带新信息，罕见能力和分布覆盖能否保留。

**Self-Rewarding Language Models**由模型生成奖励或偏好，并据此更新权重，检验生成与判断能否共同改善。共享错误需要通过独立结果评价识别。

**SEAL**把更新材料作为模型输出，内层学习后的效果训练外层编辑策略。进一步的递归判断需要重复代际、跨任务迁移、旧能力保留与更新质量比较。

## 6. 模型与 Harness 共同适配

Co-Harness、OpenRSI、MASS、SIA 等在不同时间安排和更新范围内研究模型与系统适配。[HELIX](https://arxiv.org/html/2608.13951v1)提供 Harness 组合和验证后的训练记录；第 9.5 节明确尚未训练更新模型，因此 build–update–rebuild 是后续研究循环。

共同研究的问题可表示为：

$$
H_t\rightarrow D_t^{\mathrm{verified}}\rightarrow M_{t+1}\rightarrow H_{t+1}.
$$

公开实验需要分别记录实际完成的边与提出的边。常见待补问题包括多轮循环、完整模型—Harness 交叉、冻结后新任务与父代—后继改进能力比较。该方向连接便宜的外部适配和参数中的持久学习，价值在于能设计明确的归因实验。

## 7. 会改变结论的评价研究

| 研究问题 | 对实验的影响 |
|---|---|
| 等计算比较 | Harness 搜索需要与同预算直接解题搜索比较，并说明摊销范围 |
| 统计选择 | 多候选噪声选优产生赢家偏差，需新评价或相应校正 |
| 运行与计分变化 | 日志、解析、分母、重试和评价路径可能改变观测分数，需保留原始结果 |
| 模型规模 | 弱模型可能无法使用系统结构，强模型可能已内化或被其限制，应测量曲线 |

## 8. 常见论证混淆

| 观测现象 | 能直接说明什么 | 还需要什么 |
|---|---|---|
| 当前回答自我反思 | 任务内推理与修订 | 可复用状态的保留 |
| 多次采样选优 | 更多测试时搜索有效 | 被选信息改变后续行为 |
| 固定套件高增益 | 对该任务集适配 | 未参与开发的数据迁移 |
| 更多重试、上下文或评价调用 | 更高执行预算 | 相同总资源基线 |
| 一个更好的后继 | 持久更新及可能的迁移 | 父代与后继作为改进器的比较 |
| 同时更新模型和系统 | 配对终点变化 | 组件交叉归因 |
| 生成、判断和接受共用模型 | 内部反馈循环 | 外部结果对共享错误的检验 |
| 小模型有效 | 该规模的机制证据 | 跨规模实验 |
| 新的术语与角色划分 | 新的描述方式 | 新预测、能力或受控结果 |

这些方法可能很有用；评价依据是它们实际支持的结论。

## 9. 当前证据范围

截至本次 2026 年 10 月资料整理，公开研究支持：AI 可以参与产生并保留提示、记忆、工具、源码、训练数据、奖励和权重的变化；一些变化迁移到独立任务，若干系统报告短期多代提升。

本项目继续检验的更强问题是：一般系统能否反复改善模型、Harness 和改进过程，后继更善于产生下一代，收益跨任务和规模迁移，并在变化的瓶颈下长期保持。
