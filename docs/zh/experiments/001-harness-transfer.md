# 实验 001：等总计算下的 Harness 迁移

[English](../../../experiments/001-harness-transfer.md) · [研究计划](../PROGRAM.md)

## 问题

持久 Harness 更新是否产生可复用能力，还是只摊销了更多搜索和重复基准反馈？

## 系统与条件

固定模型 $M_0$、父代 Harness $H_0$、演化版本 $H_1$，另选模型家族或规模 $M_x$。比较：

1. 标准执行预算的 $(M_0,H_0)$。
2. 获得“系统改进加后继执行”相同总计算的 $(M_0,H_0)$。
3. 标准执行预算的 $(M_0,H_1)$。
4. $(M_x,H_0)$ 与 $(M_x,H_1)$。
5. 对已选 $H_1$ 的独立重新评价。

## 任务

$P$ 是开发任务，$V$ 是有限接触的验证，$Q$ 是独立任务，$T$ 在 $H_1$ 冻结后创建。$Q,T$ 不进入候选生成、选择、调参和停止决策。

## 输出

报告独立增益、后续任务增益、等计算增益、跨模型增益、逐任务回退、成本、延迟、接受与拒绝谱系，以及计分和记录一致性。

## 解释

只在 $P$ 有效对应任务拟合；在 $Q$ 有效但等计算下消失对应搜索摊销；在 $Q,T$ 有效但不能迁移到 $M_x$，提示模型特定补偿；三者均保持才支持对应范围的可迁移 Harness 改进。
